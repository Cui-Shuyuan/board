# 动画合法性问答（手写问题，规则引擎当裁判）

> **硬规则**：cue 改一次，`qa` 必须跟着改一次。只改 script/events/state/contract、不改问题 = 未完成。过期的问句重复问新动作，等于没有校验。

- 问题全部手写，写在 `full.anim.json` 的 cue `qa` 字段或 `_qa/questions.json`；写动画时连脚本一起写。
- 问＋记日志：`python3 animation/qa_anim_ask.py`（`--list` 只看问题，`--only cue1,cue2` 只问几条）。
- `qa_anim_ask.py` 只负责提取问题、发送 Board API 问答并留档，不生成问题。
- `qa` 条目可以是字符串（默认期望「允许/合法」），也可以是 `{"q": "...", "expect": "不允许"}`；反例 cue 必须写 `expect`，否则裁判答对了也会被当成失败。
- 日志：`ask_log_<tag>.md` / `.jsonl`（最近一版是 `ask_log_handwritten.*`）。

## 手写问句的五条原则

1. **一 cue 只问它真正做的那件事**（拿宝石就问拿法；买牌就问该付什么）。
2. **只带判定需要的事实**，不要整桌抄一遍：问拿宝石就带"那堆剩几颗 + 我手上几颗"；
   问买牌就带"价格 + 我面前的折扣 + 我实付了什么"。
3. **不用教程自造词**（"样本/讲解道具"这类引擎不认识，硬问它会跟着瞎推）。
4. **规则自动发生的事就说成自动**（市场补位、贵族回合结束归属）。
5. **没有值得问的就不写**（介绍道具、纯讲解、以及"演示不同人数"的设置段）。

## 与另一层的关系

`animation/validate_anim_rules.py` 是**精确算术层**（结构化重放、逐色对账、写完脚本立刻跑，不依赖引擎）；
这里的问答是**独立裁判层**（照规则数据回答，能抓"我理解错规则"）。
