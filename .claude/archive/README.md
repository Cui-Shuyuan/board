# 归档目录

这里保存历史文档、开发日志和旧版记忆，用于追溯决策，不是新会话的必读材料。

- `memory/2026-09-23/`：整理前的 `.claude/memory/` 全量旧文档。当前有效信息已蒸馏到 `.claude/memory/` 下的新文档。
- `chat-history/`：早期完整讨论和聊天记录。
- `tutorial/`：已退役的讲规路线文档。

规则：
- 新会话默认只读 `.claude/memory/MEMORY.md` 指向的当前文档。
- 需要追溯“为什么这么设计”时，再按主题在归档里搜。
- 冲突时以当前代码、JSON 数据和 `.claude/memory/` 的新文档为准，归档仅作历史参考。
