# 立体零件 → 出图提示词 → 动画素材 流程

> 适用于**无法扫描的立体零件**（宝石筹码、木质 token、立起来的标记）。
> 平面件仍用扫描件（已验证效果好）；立体件走本流程。

## 为什么立体件不能直接扫描/抠图
- 扫描件只能扫**平面的、能压平**的（卡牌、板块）
- 立体件（宝石 token、立起来的东西）扫不了，只能拍照
- 照片背景杂、光线差、有立体反光 → **直接用照片当素材不像样**；cv2 抠图又抠不准

## 最优方案：AI 看图 → 人写提示词 → 出图模型生成
把能力放对位置：
1. **我（多模态模型）**：看照片，识别物件特征（造型/颜色/质感/细节）→ 写一份精确的出图提示词
2. **你**：把提示词拿到**免费出图模型**（即梦/豆包，中文友好）跑图
3. **得到**：一张干净、透明背景、风格统一的立体件图 → 放进动画

## 出图提示词框架（简洁插画风，面向即梦/豆包）

### 方式A：纯文字（无参考图）
```
【主体】一枚<零件名>，<形状/造型>，<结构细节>。
【颜色】<主色>，<配色细节>。
【质感】<材质/切面/反光>。
【风格】简洁插画风，干净利落矢量感，边缘清晰，去掉照片杂色和纹理。
【背景】纯透明背景(PNG)，无杂物，物件居中，适合放进桌游教学动画。
【细节】保留<关键几何特征>，不要<反例>。
```

### 方式B：参考图 + 提示词（推荐，效果好得多）★
把**实拍的零件照片**作为「结构参考图」上传（img2img / 图生图模式），再配精简提示词：
```
【任务】参考图中这颗描述的零件，重新画成简洁插画风。
【造型】保持参考图的结构：<关键造型>。
【颜色】<主色>，<配色细节>。
【风格】简洁插画风，干净矢量感，边缘清晰，去除背景杂物和照片纹理。
【背景】纯透明背景（PNG）。
【不要】<反例，如写实照片风格、背景杂物、圆滑无棱>。
```

**参考图用法（即梦/豆包/Midjourney）：**
- 上传实拍照片作结构参考（img2img）；有多张零件图就补充传
- 填精简提示词
- 调"参考强度"：太像实拍 → 提高重绘/创新度；不像 → 降低

## 标准字段（我识别→填写）
| 字段 | 说明 | 例（起始玩家标记） |
|---|---|---|
| 零件名 | 概念 id 中文 | 起始玩家标记 |
| 形状/造型 | 几何描述 | 宝石切割/钻石八面体，多面棱角，尖端 |
| 主色 | 主色调 | 蓝白冷色，冰蓝白+深蓝灰暗面 |
| 质感 | 材质切面 | 宝石切面，高光暗部对比，独立多边形切面 |
| 关键几何 | 不可丢的特征 | 棱面结构、镂空孔 |
| 反例 | 避免的 | 圆滑过渡、写实照片纹理 |
