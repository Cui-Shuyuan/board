# 动画偏好归纳

> 来源：`entries.jsonl`。新会话处理动画任务前先读本文件；需要追溯原话、状态或 commit 时再读原始条目。
> 本文件是可演进的归纳，不替代原始记录。

## 规则教学顺序

- 新规则/新动作必须按学习路径出现：先教购买和保留，再讲黄金替代购买。
- 新概念还没教之前，不要提前展示它会用到的动作。
- 黄金通常来自保留行动；讲黄金时应承接保留后的持有状态，而不是凭空出现。

## Quick 节奏

- quick 节奏紧凑，优先用短数字、计数标签和局部高亮，不写 full 式大段说明文字。
- 数量变化可以用「宝石数量：8/10」「宝石数量：11/10」「宝石数量：10/10」这类紧凑文字表达。
- 同一 cue 内用有限时长的短标签推进信息，避免标签堆叠。

## 视觉层级

- 非法值/关键值只标局部，例如只把 `11` 标红，不要整句染色。
- 反例必须视觉上可见：用禁止标记、红色数字等明确指示，不靠隐藏状态或只改口播。
- 状态变化要有连续动作支撑；不要只静默改状态就当作演示完成。

## 规则演示完整性

- 任何规则特点都要落到实际动作和完成状态：黄金万能、超过上限归还、供应不足取法。
- 演示动作前后，宝石/黄金/发展卡总数与市场补牌必须守恒。
- 能买展示卡时就要真正完成购买、进入发展区，并补回市场空位。
